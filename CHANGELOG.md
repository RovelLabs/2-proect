# История изменений (Changelog)

Все заметные изменения в проекте «Складно» документируются в этом файле в соответствии с [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и соблюдением [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-13

### Добавлено (Added)
- Полнофункциональное ядро разделения совместных расходов (Local-First React 19 + TypeScript + Vite).
- Жадный алгоритм минимизации взаимных задолженностей (из десятков хаотичных долгов создается оптимальный граф из $N-1$ переводов).
- 4 режима разделения трат:
  - «Поровну» (Equal split на всех);
  - «Выборочно» (Selective split с галочками участников);
  - «Точные суммы» (Exact split по рублям);
  - «По позициям чека» (Itemized split).
- Специализированный модуль СБП (Система быстрых платежей):
  - Автоматическое определение банка получателя (Т-Банк, Сбер, Альфа-Банк, ВТБ, Яндекс Банк, Kaspi);
  - Копирование номера телефона в один клик;
  - Генератор СБП QR-кода стандарта НСПК для моментальной оплаты в мобильном банке;
  - Deep-link вызовы банковских приложений.
- Генератор вирусных Telegram-карточек:
  - Форматирование понятной сводки с эмодзи и разбивкой по СБП для отправки в групповые чаты;
  - Мгновенная генерация shareable ссылки с закодированным LZ-String состоянием.
- Современный адаптивный UI (Mobile-First):
  - Неоново-изумрудная тема (Dark & Light modes);
  - Звуковые и тактильные микро-анимации;
  - Интерактивный режим демо-данных для быстрого ознакомления;
  - PWA манифест для добавления на домашний экран смартфона.
- Набор Unit и интеграционных тестов для проверки математики сведения долгов и краевых случаев.
- Документация: исследование рынка СНГ, архитектура, модель монетизации, стратегия роста и руководство по деплою.
